# WEURA Icons

This folder contains the icon assets used by WEURA AI.

## Design rules

- SVG preferred.
- Clean geometric shapes.
- Blue / black visual identity.
- No emoji icons.
- Consistent stroke width.
- Rounded corners where appropriate.
- Icons must remain readable at small sizes.
